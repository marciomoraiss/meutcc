# Dados para cadastro nas lojas

## Dados definidos

| Campo | Valor |
| --- | --- |
| Nome do aplicativo | MEUTCC |
| Assinatura/subtítulo | Seu TCC em acompanhamento |
| Nome comercial do publicador | TE ORIENTO |
| E-mail público de suporte | contato@teoriento.com.br |
| Categoria principal | Educação |
| Idioma principal | Português (Brasil) |
| Bundle ID iOS | br.com.teoriento.meutcc |
| Pacote Android | br.com.teoriento.meutcc |

## Dados pendentes do titular

| Campo | Por que é necessário |
| --- | --- |
| Razão social completa | Verificação jurídica das contas |
| CNPJ | Verificação da organização e documentos fiscais |
| Número D-U-N-S | Validação empresarial nas plataformas |
| Endereço e telefone comerciais | Contato e verificação da organização |
| URL de suporte | Página pública exigida para atendimento |
| URL da política de privacidade | Obrigatória para publicação e transparência LGPD |
| Responsável legal pela conta | Aceite de contratos e administração das lojas |

## Observações

- O nome comercial exibido pode depender da validação da razão social ou do nome empresarial registrado.
- O identificador técnico deve ser tratado como definitivo depois que a primeira versão for publicada.
- A disponibilidade final do nome e dos identificadores será confirmada dentro do App Store Connect e do Google Play Console.
